# Scaler Persona AI Chatbot

A premium, persona-based AI chatbot featuring the leadership of Scaler: **Anshuman Singh**, **Abhimanyu Saxena**, and **Kshitij Mishra**. Built as part of the Prompt Engineering assignment at Scaler Academy.

## ✨ Features
- **Authentic Personas**: Meticulously researched system prompts for three Scaler leaders.
- **Dynamic Switcher**: Seamlessly switch between mentors with automatic conversation reset.
- **Premium UI**: Modern glassmorphic design with persona-specific color themes.
- **Suggestion Chips**: Quick-start questions for each persona to kickstart the conversation.
- **Responsive**: Fully optimized for mobile and desktop viewports.
- **Graceful Error Handling**: User-friendly alerts for API issues or missing keys.

## 🛠️ Tech Stack
- **Frontend**: React.js + Vite
- **Styling**: Vanilla CSS (Custom Properties, Glassmorphism)
- **AI Engine**: Gemini 2.0 Flash API
- **Icons**: Lucide React

## 📦 Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone <your-repo-url>
   cd gen-ai-chatbot
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   - Create a `.env` file in the root directory.
   - Add your Gemini API Key (get it from [Google AI Studio](https://aistudio.google.com/)):
     ```env
     VITE_GEMINI_API_KEY=your_actual_api_key_here
     ```

4. **Run locally:**
   ```bash
   npm run dev
   ```
